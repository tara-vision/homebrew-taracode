# homebrew-taracode

The Homebrew tap for [taracode](https://github.com/tara-vision/taracode), the local-first DevOps operator:
a terminal agent that investigates Kubernetes, Terraform, Docker and cloud accounts by default, changes them
only through an explicit policy, and runs on [Ollama](https://ollama.com) with open models. No cloud AI,
no telemetry, MIT licensed.

## Install

```bash
brew install --cask tara-vision/taracode/taracode
```

That single command adds the tap and installs the cask. The two-step form works too:

```bash
brew tap tara-vision/taracode
brew install --cask taracode
```

The cask ships pre-built binaries for macOS (Apple Silicon and Intel) and Linux (arm64 and x86_64),
verifies their SHA-256 checksums, and clears the macOS quarantine flag, so nothing is compiled on your
machine.

## Upgrade and uninstall

```bash
brew upgrade --cask taracode
brew uninstall --cask taracode
```

The cask follows taracode's stable releases only; pre-releases never land here. Upgrading from the old
formula (retired with taracode 2.1.0)? Run `brew uninstall taracode` once, then install the cask.

## Requirements

taracode talks to a local Ollama server and needs a model with tool calling:

```bash
brew install ollama
ollama pull gemma4:12b       # 16 GB machines
ollama pull glm-4.7-flash    # 32 GB machines
ollama pull qwen3.6:35b      # 48 GB and up
```

`taracode doctor` checks the server, the installed models and the host's RAM tier, and names the
recommended model when none is configured. The recommendations come from taracode's model registry and
its published [scoreboard](https://code.tara.vision/evals).

## How this tap is maintained

`Casks/taracode.rb` is generated by [GoReleaser](https://goreleaser.com) from the release pipeline of the
main repository: every stable tag pushes a new cask with fresh checksums. Nothing here is edited by hand.
Every release also publishes `checksums.txt`, a Sigstore bundle and SLSA provenance on its
[GitHub release page](https://github.com/tara-vision/taracode/releases), so the binaries the cask downloads
can be verified independently of Homebrew.
