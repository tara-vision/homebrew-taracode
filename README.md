# homebrew-taracode

The Homebrew tap for [taracode](https://github.com/tara-vision/taracode), the local-first DevOps operator:
a terminal agent that investigates Kubernetes, Terraform, Docker and cloud accounts by default, changes them
only through an explicit policy, and runs on [taraengine](https://engine.tara.vision), the Tara Vision inference
engine, with open models. No cloud AI, no telemetry, MIT licensed.

## Install

```bash
brew install --cask tara-vision/taracode/taracode
```

That single command adds the tap and installs the cask. The two-step form works too:

```bash
brew tap tara-vision/taracode
brew install --cask taracode
```

The cask ships pre-built binaries for macOS (Apple Silicon and Intel) and Linux (arm64 and x86_64),
verifies their SHA-256 checksums, and clears the macOS quarantine flag, so nothing is compiled on your
machine.

## Upgrade and uninstall

```bash
brew upgrade --cask taracode
brew uninstall --cask taracode
```

The cask follows taracode's stable releases only; pre-releases never land here. Upgrading from the old
formula (retired with taracode 2.1.0)? Run `brew uninstall taracode` once, then install the cask.

## Requirements

taracode runs on taraengine, with a model from the engine's catalog. The engine runs on Apple Silicon Macs,
installed from this tap too, and on NVIDIA Linux machines, installed by its own script:

```bash
brew install --cask tara-vision/taracode/taraengine        # Apple Silicon Macs
curl -fsSL https://engine.tara.vision/install.sh | bash    # Linux
taraengine pull gemma4:12b       # 16 GB machines
taraengine pull glm-4.7-flash    # 32 GB machines
taraengine pull qwen3.6:35b      # 48 GB and up
```

An Intel Mac has no engine build in this release: run taracode against another OpenAI-compatible server there,
with `--host`.

taracode finds the engine at `http://127.0.0.1:8272` without configuration. `taracode doctor` checks the
engine, the pulled models and the machine's RAM tier, and names the catalog's model for it when none is
configured; which models actually do the work is measured on the published
[scoreboard](https://code.tara.vision/evals).

## taraengine

The tap also carries [taraengine](https://github.com/tara-vision/taraengine), the Tara Vision inference engine: a
local, private and OpenAI-compatible server built on llama.cpp. taracode has run on it since 3.3.0.

```bash
brew install --cask tara-vision/taracode/taraengine
```

The cask installs the binary, signed by Tara Vision, LLC and notarized by Apple, and its service. The service
starts with the first `taraengine` command and at every login. `brew upgrade --cask taraengine` restarts it on the new release,
and `brew uninstall --cask --zap taraengine` removes it with its models. It needs an Apple Silicon Mac with macOS 13 or
later. The documentation is at [engine.tara.vision](https://engine.tara.vision).

## How this tap is maintained

`Casks/taracode.rb` is generated by [GoReleaser](https://goreleaser.com) in taracode's release pipeline, and
`Casks/taraengine.rb` by `tools/rendercask` in taraengine's: every stable tag pushes a new cask with fresh checksums.
Nothing here is edited by hand. Every release also publishes `checksums.txt`, a Sigstore bundle and SLSA provenance on
its GitHub release page ([taracode](https://github.com/tara-vision/taracode/releases),
[taraengine](https://github.com/tara-vision/taraengine/releases)), so the binaries a cask downloads can be verified
independently of Homebrew.
